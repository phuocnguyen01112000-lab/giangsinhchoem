Bỏ ảnh PNG (nền trong suốt, vuông, >=128x128) vào thư mục này, tên file = id bên dưới. Chưa có ảnh thì game dùng emoji.

ẢNH POLAROID: không cần ảnh polaroid, chỉ cần bỏ ảnh của bạn vào assets/my-photo.png (hoặc my-photo.jpg), game tự lồng vào khung polaroid pixel.
